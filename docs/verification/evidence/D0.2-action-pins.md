GitHub's [secure-use guidance](https://docs.github.com/en/actions/reference/security/secure-use)
identifies a full-length commit SHA as the immutable way to reference an action. The delivery
contract allows repository-local actions because they are bound to the checked-out source SHA,
rejects unreviewed or mutable GitHub action references, and requires Docker actions to use a full
`sha256` image digest. It also rejects pin/tag-manifest disagreement.

The exact-SHA result validator also uses GitHub's
[workflow-run artifacts API](https://docs.github.com/en/rest/actions/artifacts) to verify artifact
size, SHA-256 digest, expiry, and originating workflow-run SHA before inspecting the downloaded
evidence file set.
