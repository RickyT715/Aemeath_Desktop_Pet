## TDD and failure history

The frozen RED probe first rejected the legacy workflow for missing branch/dispatch triggers,
source-SHA checkout, required-job semantics, retained evidence, and exact-SHA wait tooling. The local
GREEN suite then passed a valid workflow/result and rejected 28 known-bad mutations covering:

- missing or reduced required jobs and unjustified zero discovery;
- skipped, neutral, cancelled, incomplete, or advisory results;
- pull-request merge-SHA substitution and source-SHA mismatch;
- missing, empty, expired/short-retention, wrongly bound, or digest-less artifacts;
- missing, undersized, or unexpected evidence files;
- relocated `if: always()` conditions;
- mutable GitHub action tags and mutable Docker image references; and
- shortened artifact retention.

The first pushed implementation run,
[29908758323](https://github.com/RickyT715/Aemeath_Desktop_Pet/actions/runs/29908758323), failed closed.
Its verifier correctly rejected the merge-SHA mutation, but Ubuntu PowerShell's ANSI-colored,
line-wrapped error rendering caused the test harness to miss the expected diagnostic text. A focused
regression normalized ANSI/wrap margins while preserving the independent nonzero-exit requirement.
Independent review approved that correction before the qualifying push.

This evidence does not claim product-test coverage. D0.2 deliberately runs delivery-contract and
Release-build lanes only; Gate 0A freezes the new independent preservation test suites before Gate
0B admits or repairs legacy test/format/lint lanes.
